# 発注ノート

商品を選んで，数量を決めて，発注前に確認する．シンプルな発注チェックアプリです．

[アプリを開く](https://t-sako1126.github.io/order_app/)

## 使い方

1. 「商品管理」から商品を追加します．同じ業者の商品は1行に1つずつまとめて追加できます．
2. 「発注リスト」で業者を選び，＋・−で数量を決めます．商品名で検索もできます．
3. 「内容確認」で発注する商品を確認し，必要なら内容をコピーします．

備考は発注リスト・商品管理のどちらでも編集できます．商品は左にスワイプしてゴミ箱から削除します．

業者タブは横スワイプでスクロール，長押しして移動すると並び替えできます．商品管理では商品の二本線を長押しして，同じ業者内で並び替えできます．

商品管理の下向き矢印でCSVをインポート，上向き矢印でエクスポートできます．CSVは「業者名，商品名，備考」の3列です．重複は追加せず，読み込んだ商品の数量は0になります．

データは端末のブラウザに保存されます．商品一覧はCSVで他の人に渡せます．自動同期や実際の発注送信は行いません．

商品管理の「編集」で商品名・業者名・備考を変更できます．上部のゴミ箱アイコンで商品を選択し，確認してからまとめて削除できます．
