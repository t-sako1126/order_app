# 発注ノート

業者ごとの商品と数量を選び，発注前に内容を確認する日本語のWebアプリ．

## 初版の設計

- 発注画面：業者で絞り込み，商品名と任意の備考を表示し，数量を増減する．
- 確認画面：数量が1以上の商品を業者ごとに表示する．内容をコピーできる．
- 商品追加画面：商品名，業者名，任意の備考を入力する．
- 「まとめて追加」では業者名を共通指定し，商品名を1行に1つずつ入力する．空行と重複は除外し，備考は空欄で登録する．
- 備考は発注リスト上でも編集できる．数量は0〜999．
- サンプル商品は商品追加画面の「サンプル商品を削除」から取り除ける．自分で登録した商品は残る．
- 商品と選択数量はlocalStorageに保存する．端末間の同期は行わない．
- 実際の発注送信，ログイン，履歴は初版の対象外．
- サンプル商品を初期表示する．業務で使う商品は追加画面から登録する．

## 起動

Node.jsが入った環境で `npm run dev` を実行し，http://localhost:4173 を開く．外部パッケージのインストールは不要．

## 検証

`npm test` で数量，保存データ検証，業者別集計のテストを実行する．
